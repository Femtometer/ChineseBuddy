# 汉字小伙伴

Windows 桌面生字管理工具。使用 .NET 8 WPF，课本和手写内容通过 PaddleOCR 在线 API 识别，单字拼音通过汉语字典查询，词语及其拼音通过汉典查询。

## 运行

需要 Windows x64、.NET 8 Desktop Runtime、可访问 PaddleOCR、汉语字典和汉典的网络，以及 PaddleOCR 访问令牌。开发环境可运行：

```powershell
dotnet restore ChineseBuddy.csproj
dotnet run --project ChineseBuddy.csproj
```

生成 Windows x64 自包含发布目录：

```powershell
dotnet publish ChineseBuddy.csproj -c Release -r win-x64 --self-contained true
```

在发布目录运行 `ChineseBuddy.exe`，确保该目录可写。程序按进程、Windows 用户、系统的顺序读取 `PaddleOCR_TOKEN` 环境变量；这些变量均未设置或仅为空白时，再使用“设置”中保存的备用访问令牌。备用令牌以 Windows 当前用户保护机制加密，存储在 EXE 目录的 `ocr-token.dat`，不能直接复制到其他 Windows 用户账户使用。清除备用令牌不会修改环境变量。如果进程内保留了旧令牌，它会优先于用户变量；请从具有新环境变量的进程重新启动程序。

## 使用流程

1. 在“生字管理”导入课本 PDF，核对并编辑识别出的汉字后确认导入。也可以手动添加汉字；勾选“搜索未找到词语”可筛选没有词语的生字，并可与搜索及“仅未掌握”组合使用。
2. 在“生字管理”或“生成练习纸”中，选中一个字可以单独查询，也可以批量查询字典。生字管理页的批量查询处理全部生字；练习纸页先抽取生字，再批量查询本次抽取的字。批量查询会跳过已有拼音和带拼音词语的字，并仅请求缺失的资料，每次处理一个字；单字查询失败或所需资料为空时等待一秒后重试一次，保留已取得的部分结果。单字拼音来自汉语字典；词语从汉典返回的候选中按顺序筛选，优先保留由两个不同常用汉字组成、且在内置教材文本中连续出现的词语；教材中没有符合条件的词语时，回退到常用字规则，最多三个，按“词语(拼音)”格式保存。
3. 批量查询默认保留已有词语，并为匹配的旧词语补充拼音；勾选“批量查询时替换已有词语”可用成功取得的汉典结果替换本次抽取的字的旧词语。查询失败时保留旧词语，结果逐字保存，可用“取消当前任务”停止。核对查询结果，缺少或不合适的内容可手动编辑。生成练习纸前，每个字需要拼音和至少一个包含该字的词语，词语不能重复。
4. 生成单页 A4 PDF。默认文件名附带年月日时分，同名时自动追加序号，避免覆盖已有文件。每页最多 15 个字，按三列五行排列；未掌握的字不足 15 个时按实际数量生成。每题上方为拼音和复习统计，左侧词语的汉字与拼音分两行显示，右侧为写字方格。新版加宽词语区、缩小写字方格；过长的文字仍可能需要手动缩短。按实际大小打印，注意保留二维码和四角黑色定位标记；旧版练习纸仍可识别。
5. 在“批改练习纸”导入扫描 PDF、PNG 或 JPEG。拍照时尽量让整张纸和四角标记清晰可见。等待识别完成，参考识别建议逐题确认正确性和掌握状态。
6. 输入电脑当前时间的年月日时分（例如 `202611081430`）保存。灰色正确性复选框表示待确认，必须先切换为正确或错误。

课本 PDF 和练习纸的手写方格图片会发送给 PaddleOCR 在线服务。网络错误时可以重试；取消仅停止本地等待，已经提交的远端任务可能继续运行。

“生字管理”中的“清空生字”会在确认后清空全部生字及其复习记录，保留已生成的练习纸记录。清空前尚未提交的练习纸不能再批改，以免重新导入同一个字后误计复习次数。

## 数据

`ChineseBuddy.json` 位于 EXE 目录，包含版本号、生字表和已生成练习纸及其提交状态。时间使用带偏移的 ISO 8601 字符串。写入时生成临时文件并保留 `ChineseBuddy.json.bak` 上一版本备份；数据库无法读取时可选择恢复备份，原文件保留为 `ChineseBuddy.json.corrupt-编号`。

练习纸编号与题目快照存放在数据库中，请同时备份 JSON 和生成的练习纸。已经提交的练习纸不能再次计入复习次数。每次提交以一份数据库文件保存所有更新。

## 验证

```powershell
dotnet run --project Tests/ChineseBuddy.SmokeTests.csproj
# 额外验证当前拼音和词语在线查询：
dotnet run --project Tests/ChineseBuddy.SmokeTests.csproj -- --online
```

PDF 输出使用 Windows 已安装的“方正楷体简体”（FZKai-Z03S）显示汉字，使用宋体显示拼音。PaddleOCR 的实际手写识别效果、服务耗时和额度取决于输入质量及服务状态，保存前务必人工核对。

设置页可编辑词语黑名单，每行一个完整词语。字典查询按完整词语精确排除，内置名单覆盖部分成人、暴力、毒品和吸烟相关词语；用户保存后以 EXE 目录的 `WordBlacklist.txt` 为准，备份为 `WordBlacklist.txt.bak`。该名单不能保证覆盖所有不适合的词语，查询结果仍需核对；已有生字词语和练习纸记录不会自动修改。

单独查询一个字且获取到词语时，会保留已有的非黑名单词语、移除该字词语中的黑名单项，并补充查询结果；未取得词语时保留原词语。若词语变化导致当前搜索条件不再匹配，程序会清空搜索并定位该生字。
